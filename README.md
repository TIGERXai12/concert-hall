# 沉浸式音乐厅 · Immersive Concert Hall

浏览器端 3D 音乐厅原型。玩法类似「进厅走动、自己选座」；场景气质参照富川艺术中心音乐厅（原创低模）。

## 本地运行

```bash
cd concert-hall
python3 -m http.server 8765
```

打开：http://127.0.0.1:8765/

## 操作

- 进入 → WASD/方向键移动，鼠标环顾（手机：左摇杆 + 右滑）
- 走近座位点击入座；标签形如「一楼 B区 5排 8座」「二楼 P区·合唱 2排 3座」
- 可坐到舞台后方合唱席看乐团背面；「起身换座」换位置
- 音乐按钮切换占位音轨（可日后替换真曲目）


## 舞台与音响

- 协奏布局：黑亮三角钢琴在台口中央（琴尾朝乐团/上台口，键盘在观众左侧，独奏者侧对观众）；盖板朝观众打开；指挥台在钢琴曲线后方，指挥站在台上；弦乐外移让位
- 占位音乐用多路 `PositionalAudio`（弦乐 L/R、木管、铜管、打击、**钢琴**）；曲目可替换 `assets/audio/placeholder.mp3`

## 座位区划（简化版）

对照富川厅字母区：一楼 A/B/C（正对舞台）、D/F（侧席）；二楼后排与 L/R 侧廊、**P 合唱席**；三楼上层。座位数为性能缩略，非 1445 全量。
